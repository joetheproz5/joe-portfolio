# Joe Ghaoui — Portfolio

A dark, project-first portfolio for Joe Ghaoui: Software Developer and Computer Science Student.

## Stack

- Next.js App Router
- React + TypeScript
- Tailwind CSS
- Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project content

Portfolio project details live in `src/data/projects.ts`. Add future screenshots to `public/` and their paths to the matching project object; the current interfaces are deliberately styled placeholders until those screenshots are ready.

## Check production build

```bash
npm run build
npm run lint
```
